## Agent skills

### Issue tracker

Issues y specs viven en GitHub Issues y se gestionan con `gh`. Ver `docs/agents/issue-tracker.md`.

### Triage labels

Se utilizan las etiquetas predeterminadas: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human` y `wontfix`. Ver `docs/agents/triage-labels.md`.

### Domain docs

Repositorio de contexto único, con `CONTEXT.md` en la raíz y ADRs en `docs/adr/`, creados solamente cuando corresponda. Ver `docs/agents/domain.md`.
