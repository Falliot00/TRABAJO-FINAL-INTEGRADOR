# Preservar fichas confirmadas como snapshots

Cada ficha confirmada conservará un snapshot autocontenido e inmutable y su representación PDF, de modo que cambios posteriores en personas, vehículos o componentes no reescriban la historia. Los errores se resolverán mediante rectificaciones enlazadas, aceptando el costo de duplicar datos históricos para obtener trazabilidad y capacidad de reconstrucción documental.
